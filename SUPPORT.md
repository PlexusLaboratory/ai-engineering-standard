# Support

## Where to ask for help

Use the channel that best matches the request once the repository enables it:

- **Documentation question or usage help:** GitHub Discussions or a support issue.
- **Reproducible defect:** the bug-report issue form.
- **Feature proposal:** the feature-request issue form.
- **Security concern:** [SECURITY.md](SECURITY.md), never a public issue.
- **Conduct concern:** [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) and a private maintainer channel.

## How to make a support request actionable

Include the relevant version or commit, environment, exact steps, expected and actual behavior, and a small sanitized example. Remove tokens, private URLs, personal data, production records, and confidential logs before posting.

## Scope

Support is best-effort until project owners publish service levels, supported environments, or commercial support terms. Maintainers may redirect requests that are unrelated to this project or lack enough information to investigate.
