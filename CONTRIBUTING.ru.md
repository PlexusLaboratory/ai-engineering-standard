# Участие в проекте

Спасибо за вклад в проект. Изменения должны делать репозиторий безопаснее, понятнее или полезнее, не создавая избыточной сложности.

## Перед началом

1. Прочитайте [INSTRUCTIONS.md](INSTRUCTIONS.md), [CODE_OF_CONDUCT.ru.md](CODE_OF_CONDUCT.ru.md) и этот документ.
2. Проверьте существующие issue и обсуждения, чтобы не создавать дубликат.
3. Для существенной функции, изменения API, миграции или чувствительной к безопасности работы сначала обсудите ожидаемый результат.
4. Не включайте секреты, приватные данные, защищённые чужие материалы и несвязанные изменения.

## Процесс внесения изменений

1. Опишите проблему, ожидаемый результат, затронутых пользователей и ограничения.
2. Внесите наименьшее цельное изменение, решающее задачу.
3. Обновите тесты и документацию, если меняется поведение, конфигурация, интерфейс или эксплуатационный процесс.
4. Выполните проверки, соответствующие уровню риска; укажите, какие проверки не удалось запустить и почему.
5. Откройте сфокусированный pull request по шаблону репозитория.
6. Конструктивно отвечайте на замечания ревью и обновляйте ветку по запросу.

## Ожидания по качеству

- Соблюдайте правила архитектуры, безопасности, тестирования и совместимости из [INSTRUCTIONS.md](INSTRUCTIONS.md).
- Сохраняйте обратную совместимость, если только изменение не описывает переход с нарушением совместимости.
- Для значимых изменений логики включайте негативные и граничные сценарии.
- Делайте коммиты и pull request узкими по цели; по возможности отделяйте рефакторинг от изменения поведения.
- Пишите ясную, уважительную документацию на языке(ах), принятых для изменяемого файла.

## Сообщение об ошибках и предложения функций

Используйте двуязычные формы GitHub issue из [`.github/ISSUE_TEMPLATE/`](.github/ISSUE_TEMPLATE/). Не публикуйте предполагаемые уязвимости в issue: следуйте [SECURITY.ru.md](SECURITY.ru.md).

## Ревью и слияние

Мейнтейнеры оценивают корректность, безопасность, границы задачи, тесты, документацию, совместимость и поддерживаемость. Pull request может быть отклонён, если его польза не оправдывает сложность и стоимость поддержки. Одобрение не снимает ответственности за нераскрытые риски или внешние последствия.

## Лицензия и соглашение участника

Лицензия репозитория пока не выбрана. Не отправляйте код или материалы, на которые у вас нет прав. После выбора лицензии вклады будут регулироваться её условиями, если мейнтейнеры не опубликуют другое соглашение.
